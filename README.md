#Descripción del Proyecto
Este programa en Python resuelve la problemática cotidiana de administrar y evaluar el rendimiento académico de un grupo de estudiantes. Permite registrar de manera dinámica a múltiples alumnos junto con sus respectivas calificaciones, automatizando el cálculo de promedios individuales y obteniendo estadísticas generales del grupo.
